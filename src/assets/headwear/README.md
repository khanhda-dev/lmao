# User-supplied headwear artwork

Extracted without redrawing or recoloring from the supplied 1844 × 602 SVG.
Five illustrations: nón ba tầm, khăn đóng (female), khăn vành dây,
nón dấu, and khăn xếp (male). Original paths, paint, opacity and ordering
are preserved in separate rear/front groups. HeadwearSVG.ts attaches these
groups using the illustrated eye-line and head axis; it scales shared hats
uniformly to the other model's head size. Wrapped female headwear replaces
the original back hair to retain the supplied silhouette.
